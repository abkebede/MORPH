# Contributing to MORPH

Contributions should preserve scientific transparency and reproducibility.

Before proposing a new module or analysis:
1. State the physical problem and equations.
2. Define all inputs, outputs, units, and conventions.
3. Include a small reproducible example where licensing permits.
4. Document numerical parameters and software dependencies.
5. Add a validation test or comparison.
6. Avoid embedding undocumented empirical corrections in analysis code.

Code contributions should be modular and should not silently modify raw data.
